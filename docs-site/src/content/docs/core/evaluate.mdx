title: Evaluation
description: Evaluate shared JSON state with typed Choice, Score, and Boolean questions.

`AI.experimentalEvaluate` is the provider-neutral Evaluation Model V4 facade.
TypeSafe AI exposes its native `/systemone` evaluator through
`AIProviders.typeSafeAI().evaluationModel("jev-latest")`; OpenAI, Anthropic,
and Google adapt language models, while Gateway exposes its native evaluation
endpoint.
It sends one shared JSON state and a keyed question map, validates provider
support and every returned answer, retries transient failures, and preserves
usage, warnings, rounding, provider metadata, and response metadata.

## Evaluate with a language-model adapter

OpenAI, Anthropic, and Google expose `evaluationModel(_:)`. Their adapters use
strict structured output while keeping the provider's request builder,
headers, options, abort signal, and response parsing.

```swift
let anthropic = try AIProviders.anthropic()
let model = try anthropic.evaluationModel("claude-sonnet-4-6")

let result = try await AI.experimentalEvaluate(
    model: model,
    state: [
        "answer": "Paris",
        "reference": "Paris"
    ],
    questions: [
        "correct": .boolean(
            instructions: "Does the answer match the reference?"
        ),
        "quality": .score(
            instructions: "Rate answer quality.",
            criteria: ["Incorrect", "Partially correct", "Fully correct"]
        ),
        "tone": .choice(
            instructions: "Classify the tone.",
            criteria: [
                "neutral": "Plain and factual.",
                "promotional": "Persuasive or sales-oriented."
            ]
        )
    ],
    providerOptions: ["anthropic": ["effort": "high"]]
)

if case let .boolean(probability)? = result.answers["correct"] {
    print(probability)
}
```

Choice criteria are keyed labels. Score criteria are an ordered rubric and can
return a finite fractional position inside its zero-based range. Boolean
answers are `P(true)` in `0...1`; they are not thresholded into a `Bool`.

## Use a native Gateway evaluation model

Gateway sends the Evaluation V4 wire contract directly:

```swift
let gateway = try AIProviders.gateway()
let model = try gateway.evaluationModel("typesafe-ai/jev-latest")
let result = try await AI.experimentalEvaluate(
    model: model,
    state: ["response": responseText],
    questions: [
        "safe": .boolean(instructions: "Is the response safe?")
    ]
)
```

This does not imply a direct `@ai-sdk/typesafe-ai` Swift provider. Gateway
routes the model; a standalone Typesafe AI provider remains a separate port.

## Registry and custom providers

`AIProviderRegistry` resolves `provider:model` evaluation IDs when the routed
provider conforms to `AIEvaluationProvider`. `customProvider` can register
direct `AIEvaluationModelReference` values or fall back to another provider.
Invalid question maps, unsupported question types, missing or extra answers,
out-of-range values, and invalid provider versions fail before an unvalidated
result reaches the application.
