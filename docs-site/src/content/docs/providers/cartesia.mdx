## Notes

Cartesia REST speech, batch transcription, and Ink 2 streaming transcription mirror upstream 3.0.29: `CARTESIA_API_KEY`, Bearer auth, `Cartesia-Version` default `2026-03-01`, custom headers and Swift base-URL override, versioned user-agent suffix, speech/transcription aliases, `/tts/bytes` JSON speech, `/stt` multipart batch transcription, and `/access-token` plus duplex `/stt/turns/websocket` or `/stt/websocket` streaming. Streaming supports raw PCM/G.711 encodings, server turn detection or explicit finalization, partial/final events, raw chunks, token-redacted metadata, cancellation, and an injectable `AIDuplexWebSocketTransport`. Full realtime speech-session generation remains a broader protocol gap; `ink-2` batch calls still fail locally before network I/O.
