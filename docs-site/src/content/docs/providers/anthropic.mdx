## Notes

Anthropic mirrors upstream 4.0.21 across Messages, files, and skills: thinking, citations, cache control, hosted/provider-defined tools, streamed code-execution input subtypes, `fallbacks: default` beta routing, Claude Opus 5 and forward-compatible Claude capabilities, structured-output tool safeguards, reasoning-token usage details, and provider metadata. Mid-conversation system-message `toolChanges` map to tool-addition/removal content blocks with automatic beta headers, while initial-system changes warn and are ignored; toolChanges-only empty text does not consume an invisible cache breakpoint. `thinking: disabled` is forwarded and incompatible `xhigh`/`max` effort is lowered with a warning. Files and skills clients add the required Anthropic beta headers.

Factory argument requirements are defined by the public Swift factory signatures. Use [Public symbols](../reference/generated/public-symbols/) when you need the exact initializer or factory declaration.
