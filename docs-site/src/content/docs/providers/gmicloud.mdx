## Notes

GMI Cloud chat mirrors upstream 3.0.6: `GMI_CLOUD_APIKEY`, bearer auth, custom base URL and headers, versioned user-agent suffix, callable/language/chat aliases, forward-compatible string model IDs, OpenAI-compatible chat streaming, usage enabled by default with unknown usage fields preserved, and nested JSON `error.details` unwrapping for actionable backend diagnostics. Embedding and image families remain unsupported.
