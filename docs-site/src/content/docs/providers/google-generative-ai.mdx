## Notes

Google Generative AI mirrors upstream Google 4.0.50 across Gemini language, embeddings, Gemini image generation, Gemini TTS speech, Veo video, files, interactions models, and agents. Imagen factories remain locally available for source compatibility after their removal from the current upstream package. Gemini 3.7 Flash normalizes `none` and `minimal` reasoning to the supported `low` thinking floor. Primitive JSON Schema enum/const values and local `$ref` expansion, including boolean-schema references, map to Gemini's OpenAPI-compatible wire form, while strict forced/named tools use `ANY` and strict automatic tools retain `VALIDATED`. Interactions forwards topK and seed while warning for unsupported penalties and agent-dropped settings; Files resumable uploads leave payload length to the transport. Generate and stream results surface Gemini `responseId`; multiple code-execution results retain their originating call ID; parallel unsigned function calls reuse an earlier signed standard call; and unknown future Gemini IDs default to the newest supported tool, thinking, file-search, and multimodal response capabilities while known legacy families stay conservative. Speech maps Gemini TTS generateContent requests with WAV-wrapped PCM by default, raw PCM opt-in, multi-speaker provider options, response sample-rate metadata, and upstream warnings. Realtime/WebSocket speech translation and lifecycle events and JS ProviderV4 runtime helpers remain gaps.

Factory argument requirements are defined by the public Swift factory signatures. Use [Public symbols](../reference/generated/public-symbols/) when you need the exact initializer or factory declaration.
