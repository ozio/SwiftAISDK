## Notes

Black Forest Labs image and FLUX 3 video generation mirror upstream 2.0.35: `BFL_API_KEY`, `x-key` auth, custom base URL and headers, versioned user-agent suffix, `image`/`imageModel` and `video`/`videoModel` aliases, `black-forest-labs.image` and `black-forest-labs.video` provider IDs, `/v1/{model}` submit URLs, response-supplied polling with trusted `bfl.ai` sibling-host credential forwarding, signed result URLs, provider options and warnings, response/provider metadata, and structured errors. Video supports text-to-video, first/last/timed keyframes, continuation, draft generation/enhancement, and settled cost metadata. Unary generation remains source compatible; `AsyncVideoModel` adds serializable V4 start/status operations, stable idempotent start retries, and shared facade polling. BFL has no native webhook, so a supplied webhook warns and falls back to polling. Language and embedding families remain unsupported.

Factory argument requirements are defined by the public Swift factory signatures. Use [Public symbols](../reference/generated/public-symbols/) when you need the exact initializer or factory declaration.
