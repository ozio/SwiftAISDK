## Notes

ByteDance Seedance video models mirror upstream ByteDance 2.0.37: `ARK_API_KEY`, versioned user-agent suffix, current Dreamina/Seedance model IDs, prompt/image/frameImages/inputReferences mapping, standard unary generation plus public AsyncVideoModel start/status operations, provider options for watermark/camera/returnLastFrame/serviceTier/draft/reference media/polling, resolution mapping, warnings, polling/error metadata including returned last-frame URLs, and unsupported non-video families. Upstream image-token usage has no local analogue because this provider exposes video only.

Factory argument requirements are defined by the public Swift factory signatures. Use [Public symbols](../reference/generated/public-symbols/) when you need the exact initializer or factory declaration.
