## Notes

Chat and embedding endpoints mirror upstream Baseten 2.1.19: `BASETEN_API_KEY`, versioned user-agent suffix, custom Model API base URL, `/sync/v1` chat model URLs, `/sync` or `/sync/v1` embedding model URLs, OpenAI-compatible HTTP embedding bodies/options with 128-input batching, native JSON Schema structured output enabled by default, streamed chat usage enabled by default, unsupported image models, and both string and nested OpenAI-shaped `error` envelope parsing. The optional native NAPI performance client is JavaScript-specific.

Factory argument requirements are defined by the public Swift factory signatures. Use [Public symbols](../reference/generated/public-symbols/) when you need the exact initializer or factory declaration.
