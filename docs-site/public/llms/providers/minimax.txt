## Notes

MiniMax language models mirror upstream 3.0.1: `MINIMAX_API_KEY`, custom base URL and headers, versioned user-agent suffix, callable provider plus `languageModel`/`chat` aliases, `minimax.messages` provider IDs, no URL attachment support, and explicit unsupported embedding/image families. The provider reuses the Anthropic Messages request builder, error handling, streaming lifecycle, telemetry metadata, and ordered generate-content parser, including signed/redacted reasoning, citation metadata, and compaction, while reading provider options from `minimax`; public MiniMax thinking options use adaptive or disabled mode. The requested 3.0.0 source is byte-identical to 3.0.1 apart from version/dependency propagation.

Factory argument requirements are defined by the public Swift factory signatures. Use [Public symbols](../reference/generated/public-symbols/) when you need the exact initializer or factory declaration.
