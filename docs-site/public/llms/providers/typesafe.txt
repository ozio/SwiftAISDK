## Notes

TypeSafe AI mirrors upstream 3.0.17 with native Decision V4 text/JSON state, /systemone Choice/Score/Boolean evaluation, published question limits, two-decimal rounding, confidence/usage metadata, lazy bearer auth, versioned user-agent and strict errors. Existing Evaluation V4 factories remain source compatible. File evidence and other model families are unsupported; JavaScript workflow serialization stays out of scope.

Factory argument requirements are defined by the public Swift factory signatures. Use [Public symbols](/reference/generated/public-symbols/) when you need the exact initializer or factory declaration.
