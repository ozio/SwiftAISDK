## Notes

Azure OpenAI mirrors upstream 4.0.90: `AZURE_API_KEY` or per-request Microsoft Entra token provider auth, `AZURE_RESOURCE_NAME`, versioned user-agent suffix, Responses as default callable/language surface, chat/deepseek/completion/embedding/textEmbedding/image/transcription/speech aliases, Azure provider metadata namespace, deployment-based transcription URLs, Azure OpenAI base URLs with `/v1` and `api-version`, custom non-Azure gateway base URLs used as-is, DeepSeek reasoning mapping without thinking support, OpenAI option namespace mapping, Azure content-filter placeholder metadata suppression, and Azure-specific hosted tool helpers. The 4.0.63 pass normalizes Azure OpenAI, Foundry, Cognitive Services, custom gateway, deployment, and `/v1` URL shapes without duplicating `/v1` or `api-version`, and inherits the shared OpenAI GPT-6 request behavior. Files V4 remains exposed by the OpenAI and xAI file clients. The 2026-09-27 pass inherits strict-false function tools and validated, positioned GPT-6 reasoning-effort updates from the shared OpenAI Responses path. The 2026-10-04 pass adds MAI Voice 2/2.1 and Flash Speech synthesis with SSML/style/voice/format handling, MAI Transcribe 1.5/2 file transcription with timed phrase metadata, and MAI Transcribe 2 streaming over an injectable cancellable WebSocket. AzureOpenAIAudioSettings configures separate Speech/MAI base URLs. Entra auth applies to both audio hosts; generated resource names must be single DNS labels. Azure image file/mask capabilities are unknown.
