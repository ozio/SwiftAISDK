## Notes

xAI mirrors upstream 4.0.43: `XAI_API_KEY`, custom base URL and headers, versioned user-agent suffix, callable/language Responses default, chat/responses/image/video/files aliases, no-argument `speech`/`speechModel` and `transcription`/`transcriptionModel` aliases, Responses provider options and hosted tools with blocked-domain filters and complete unsupported-sampling warnings, Grok 4.6 `xhigh` reasoning and priority service-tier metadata, streamed/generated Responses image-generation calls with prompt and failure results, image generation/editing, Imagine Video 1.5 generation/edit/extend/reference modes with 1080p, reference voices, resilient polling, and terminal moderation/missing-URL errors, `/tts` speech generation with voice/language/output_format, timestamps, pronunciation replacements, trace/usage metadata, and provider options, `/stt` multipart batch transcription with options and word segments, Files API provider references, response metadata, and xAI error schema. The provider-neutral Realtime V4 contract and duplex session are implemented with xAI ephemeral-secret creation, expiry metadata, authenticated WebSocket configuration, session/audio/text/tool/custom event serialization and parsing, pre-open queuing, health replies, cancellation, and close metadata. OpenAI and Google realtime adapters, ProviderV4 type names, ESM-only packaging, Node 22 engines, and workflow serialization helpers remain deferred or JS-only concerns.
