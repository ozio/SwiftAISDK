## Notes

ByteDance Seedance video models mirror upstream ByteDance 2.0.48: `ARK_API_KEY`, versioned user-agent suffix, current Dreamina/Seedance model IDs, prompt/image/frameImages/inputReferences mapping, standard unary generation plus public AsyncVideoModel start/status operations, provider options for watermark/camera/returnLastFrame/serviceTier/draft/reference media/polling, resolution mapping, warnings, polling/error metadata including returned last-frame URLs, and unsupported non-video families. Upstream image-token usage has no local analogue because this provider exposes video only. Status polling now follows only validated redirects and never forwards credentials away from the configured origin. The 2026-09-20 pass emits `reference_image` when a start image is combined with additional references.
